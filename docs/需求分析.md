## 1. 项目概述

### 1.1 一句话定位

一款跑在 **iPhone 与鸿蒙手机**上的**本地优先个人交易手账**：随手记交易、自动算持仓、天天写复盘、长期看统计。

> 每一笔交易都有据可查，每一天都有复盘可回。

### 1.2 背景与要解决的问题

| 现状痛点 | 本软件的解法 |
|---|---|
| 交易记录散落在备忘录 / 微信 / 脑子里 | 30 秒记一笔，标的自动补全、自动关联持仓 |
| 持仓成本只会在券商 App 里看，买卖思路过两天就忘 | 交易流水自动汇总成持仓成本与"已了结交易"完整档案 |
| 复盘三天打鱼两天晒网 | 日历视图 + 收盘后本地提醒，哪天没复盘一目了然 |
| 不知道自己长期到底赚不赚、错在哪 | 胜率 / 盈亏比 / 净值曲线 / 按策略标签归因 |
| "今天到底赚了多少"靠感觉，已实现和浮盈混成一笔糊涂账 | 今日页直接给当日总盈亏（已实现 + 浮动变化，现金中性口径，见 §5.11） |

### 1.3 目标用户

单一用户（本人）自用。无社交、无多用户、无内容分发，数据完全私有。

## 2. 可行性结论：好搞吗？

**结论：好搞。属于中低复杂度的纯工具类应用，MVP 一人（AI 辅助开发）完全可行。**

- 功能本质 = 表单录入 + 本地数据库 + 列表 / 日历 / 图表展示。无实时行情依赖（第一版手动填价）、无支付、无社交、无后台服务。
- 真正的工程成本只有三处，且都可以"先简后繁"规避：

| # | 难点 | 说明 | 规避方式 |
|---|---|---|---|
| 1 | 鸿蒙 NEXT 不兼容安卓 | HarmonyOS NEXT（纯血鸿蒙）不再运行安卓 APK，"打个安卓包就完事"这条路不存在 | 选能编译到 OpenHarmony 的跨端框架（见 §3） |
| 2 | iOS 打包需要 Mac | 当前开发机是 Windows：可开发鸿蒙端、安卓端和全部业务逻辑，但 iOS 编译/签名必须 macOS + Xcode | 云 Mac 服务或 CI 打包（如 GitHub Actions 的 macOS runner）+ TestFlight 安装 |
| 3 | 自动行情 / 云同步 | 行情接口有稳定性与维护成本；跨 iPhone↔鸿蒙同步必须自建后端 | 第一版一律不做：手动填价 + 纯本地存储，复杂度直接砍掉约 80% |

### 2.1 分发与账号成本（自用 vs 上架）

| 平台 | 自用 | 上架 |
|---|---|---|
| iOS | Apple 开发者账号 $99/年，走 TestFlight 安装 | 同左，另需过 App Store 审核 |
| 鸿蒙 | 华为个人开发者账号（免费实名认证），内部测试 / 自行安装 | 上架华为应用市场审核 |
| 免费 Apple 账号直接装机 | 签名 7 天过期，需反复重装，不推荐 | — |

## 3. 技术方案分析

### 3.1 平台策略

同时支持 iOS 与 HarmonyOS NEXT，一套代码优先。

### 3.2 技术选型对比

| 方案 | 一套代码？ | 鸿蒙支持 | 优点 | 缺点 |
|---|---|---|---|---|
| **Flutter（推荐）** | iOS / 鸿蒙 / 安卓三端 | OpenHarmony SIG 官方移植版（flutter_flutter） | UI 一致、性能好、图表用纯 Dart 库无适配坑、维护一份代码 | 部分插件需用鸿蒙社区适配版（主流插件大多已有） |
| React Native（RNOH） | iOS / 鸿蒙 | 华为官方 RNOH | 前端生态大、JS 生态复用 | 依赖原生模块多时适配成本高 |
| uni-app x | iOS / 鸿蒙 / 安卓 | DCloud 官方支持 | 中文文档全、上手最快 | 性能与深度定制弱于 Flutter |
| 原生双端 | 否，SwiftUI + ArkTS 两套 | 原生 ArkTS | 体验与系统能力最佳 | 工作量约两倍，业务逻辑写两遍 |

**推荐 Flutter**，理由：

1. 一套 Dart 代码 → iOS + 鸿蒙（安卓白送），业务逻辑与 UI 全复用，长期只维护一份代码；
2. 鸿蒙侧移植版由 OpenHarmony SIG 官方维护，数据库 / 通知 / 图片选择等主流插件均有 ohos 适配版；
3. 本 App 的核心 UI（流水表、日历、图表）用纯 Dart 图表库（fl_chart 等）即可实现，恰好绕开插件适配的坑。

### 3.3 技术栈明细（以 Flutter 为例）

| 层 | 选型 |
|---|---|
| 框架 | Flutter（stable）+ flutter_flutter(ohos) |
| 本地数据库 | SQLite（drift / sqflite，均有鸿蒙适配） |
| 图表 | fl_chart（纯 Dart） |
| 状态管理 | Riverpod |
| 本地通知 | flutter_local_notifications（ohos 适配版） |
| 后端 | v1 无；v2 可选 Supabase / 自托管轻 API |

### 3.4 数据与后端策略

- **v1 纯本地**：数据只存手机（SQLite），支持导出备份文件与 CSV。零服务器、零隐私风险、零运维。
- **v2 可选云同步**：注意 iCloud 不通鸿蒙、华为云不通 iPhone，跨 iPhone↔鸿蒙同步必须自建后端。属于后置决策，不影响 v1 架构。

## 4. 典型使用场景

1. **盘中随手记**：刚买了一手，点"记一笔"→ 选最近用过的标的 → 填价格数量 → 补一句买入理由 → 30 秒完成。
2. **盘后例程**：收盘后打开今日页，跟着"盘后三件事"走——批量填一次价（列出全部持仓逐个填，30 秒完成）→ 看当日总盈亏 → 写复盘（详见 §5.11）。
3. **每日复盘**：19:30 收到提醒 → 复盘页看到今天自动带出的交易清单 → 写做对了什么 / 做错了什么 / 明日计划 → 打纪律分 → 存档。
4. **周末统计**：统计页看本周胜率、盈亏比、净值曲线，按"追涨"标签筛出亏损贡献最大的毛病。
5. **回溯历史**：三周后想知道"当时为什么买它"，在已了结交易里点开完整买卖配对 + 当时的截图和理由。

## 5. 功能需求

优先级定义：**P0** = MVP 必须；**P1** = 第二迭代；**P2** = 远期可选。

### 5.1 交易记录（核心，P0）

- 记一笔：日期时间（默认当前）、市场、代码 / 名称（常用标的自动补全 + 最近使用 + 收藏）、方向（买入 / 卖出）、价格、数量、手续费
- 附注：买卖理由（文字）、K 线 / 分时截图（多张）、标签（策略 / 板块）、情绪标记（冷静 / 冲动 / FOMO / 止损……）
- 交易流水：按交易日分组倒序展示，支持按标的 / 方向 / 标签 / 日期区间筛选
- 编辑、删除（二次确认）、复制一笔；**编辑任意一笔后全账即时重算**（持仓/已了结/统计都由流水推导，改错零心理负担）
- 记账提速四件套（v0.3，目标：常用标的 15 秒记完一笔）：
  - 常用标的一键选择：收藏 + 最近使用置顶成候选条，不必每次输代码
  - 数量快捷步进：±100 / ±500 / ±1000 股快捷按钮
  - 手续费自动估算：按设置费率预填（佣金可设万几/最低 5 元、印花税卖出、过户费），金额可手改
  - 卖出参考：卖出表单内直接显示该标的当前持仓数量与摊薄成本，边填边算预计盈亏
- 删除保护：软删除 + 回收站（P1，保留 30 天）

### 5.2 持仓管理（核心，P0）

- 由交易流水**自动计算**当前持仓：持仓数量、摊薄成本（手续费计入成本）、已实现盈亏
- 浮动盈亏：手动填当前价 → 显示浮盈金额 / 比例、仓位占比
- 批量填价模式（v0.3）：盘后一个界面列全部持仓逐个填价，未填价醒目标注，支持"沿用上次价格"一键带出；填完即出当日总盈亏
- 已了结交易档案：清仓后自动归档，保留完整买卖配对、持仓天数、单笔盈亏与当时的理由截图
- 持仓快照：每次复盘保存时自动生成当日资产快照（构成净值曲线数据源）
- 成本手工调整：分红 / 送股 / 拆股时手动修正成本（v1 方案；公司行动自动记录为 P2）
- 入金 / 出金记录（P1）：配合期初本金计算真实收益率

### 5.3 每日复盘（核心，P0）

- 日历视图：每格标注当日盈亏（红 / 绿）与是否已复盘（实心 / 空心），点击进入当天
- 复盘表单（固定模板，v1）：
  - 大盘简评（一句话 + 截图）
  - 当日操作回顾（自动带出当日交易清单）
  - 做对了什么 / 做错了什么
  - 明日计划
  - 心态自评（1–5）
  - 纪律清单打勾（如：按计划执行 / 未追涨杀跌 / 仓位未超限 / 执行了止损）
  - 截图若干
- 周复盘 / 月复盘模板（P1）
- 复盘模板字段自定义（P2）

### 5.4 统计分析（P0 基础 / P1 进阶 / P2 远期）

- P0：累计已实现盈亏、胜率、盈亏比（平均盈利 ÷ 平均亏损）、交易笔数、手续费合计
- P1：资产净值曲线（依赖 §5.12 入金出金）、最大回撤、按标签（策略/情绪）归因、按标的 / 星期 / 时段分布、月度报表、当日总盈亏趋势（见 §5.11）
- P2：券商对账单导入（同花顺 / 东财等格式）、AI 周报生成

### 5.5 价格与行情

- v1：全部手动输入（收盘价 / 现价），零外部依赖
- P2：接入延迟行情接口自动刷新 A 股价格（第三方接口的稳定性与合规需单独评估）

### 5.6 数据安全与备份（P0）

- 数据 100% 本地存储，不集成任何第三方统计 / 广告 SDK
- 导出：CSV（交易流水）+ 完整备份文件（可在新设备恢复）
- 自动备份（v0.3 升为 P0）：每日首次启动自动整库备份一份，保留最近 10 份（可设置关闭/调整）——月月积累的交易手账是唯一资产，误删/坏库必须可恢复
- 应用锁：面容 / 指纹 / 密码（P1）
- 危险操作二次确认（删除交易、清空数据）

### 5.7 提醒与设置（P1）

- ~~每日收盘后复盘提醒~~ → **砍掉**（2026-08-29 用户决策）：目标用户每天盯盘，不存在"忘记复盘"；未复盘问责由复盘日历的空格可视化承担
- 本地通知基建（权限/插件/定时）整体顺延至 M7 自选盯踪的到价/止损条件提醒时一并实现
- 深色模式跟随系统、期初本金设置、数据导出入、关于页

### 5.8 交易计划（P1，推荐新增）

复盘闭环的关键一环：盘前写计划 → 盘后对照执行。

- 盘前计划：日期、关注标的（代码/名称/方向/预期买点/仓位上限/止损位）、备注
- 盘后对照：当日实际交易与计划自动匹配，标记"计划内 / 计划外"
- 纪律数据源：计划外交易占比进入统计与 AI 分析原料
- 与"明日计划"字段打通：今日复盘的明日计划自动成为次日盘前计划草稿
- 与记一笔打通（v0.3）：盘中记账时若当日计划含该标的，自动标记"计划内"并预填情绪；不在计划中的交易记完即时提示"计划外"，写理由时可对照

### 5.9 AI 辅助复盘（M6，2026-08-29 立项；v0.3 由 M4 平移）

定位：AI 做**解读和提问**，不做计算——统计数字一律来自本地引擎，AI 输出标注"仅供参考"。

分三步交付：

| 阶段 | 功能 | 说明 |
|---|---|---|
| AI-1 | AI 周报 / 月报 | 打包近 N 天结构化数据（交易+情绪标签+纪律执行+盈亏+复盘摘要）→ 调用大模型 → 生成 Markdown 报告（亏损模式、纪律执行率变化、情绪-盈亏关联），可保存到复盘库 |
| AI-2 | 复盘草稿辅助 | 盘后根据当日交易自动起草复盘要点（做对/做错/明日计划草稿），用户修改后保存 |
| AI-3 | 对话式追问 | 基于全部交易历史的问答（"我追涨的票整体表现如何"），近期数据直塞上下文，无需 RAG |

技术方案与约束：

- 模型：国内可直连的 OpenAI 兼容 API（智谱 GLM / DeepSeek 等），设置页配置 Provider + API Key + 模型名
- 数据出设备须**显式开关**，支持脱敏模式（只传代码/金额/标签，不传备注与复盘原文）
- 网络层为独立可选模块，离线核心功能零依赖；无网/未配置时 AI 入口降级隐藏
- 成本：轻量模型下每月数元以内
- 前置条件：真机日常使用积累 ≥1 个月数据后再上线，数据太少分析无意义

### 5.10 自选盯踪（M7，2026-08-29 立项；v0.3 由 M5 平移）

定位：**与自己的账本挂钩的盯踪**——差异化在于所有行情与提醒都关联"我的成本 / 我的计划 / 我的历史交易"，而非通用行情软件。

- 自选列表：关注标的 + 现价 / 涨跌幅（`instruments.is_favorite` 已有字段基础）
- 账本关联提示：现价相对我的持仓成本 / 已了结盈亏 / 计划买点的位置
- 条件提醒：到价 / 跌破止损 / 到达目标位 → 本地通知（含价格、与成本的差距）
- AI 近况简报（依赖 §5.9 AI 底座）：近 60 日行情 + 我在该标的的全部交易 → 生成近况解读（趋势 / 量能 / 相对成本态势 / 计划触发情况）

技术约束与方案：

- 行情源：新浪 / 腾讯延迟行情接口（个人自用，无官方 SLA，接口层做容错与可替换）
- 后台限制：鸿蒙 / iOS 均不允许常驻后台盯盘。方案三层：打开 App 时刷新（主路径）+ 每日盘后定时后台刷新一次（系统后台任务代理）+ 条件触发本地通知（提醒有分钟级延迟，对复盘场景够用）
- 联网为可选模块（显式开关），未开启时自选页降级为纯手动记录
- 分期：自选页+刷新+成本关联 → 条件提醒 → AI 简报

### 5.11 盘后例程与当日总盈亏（v0.3 新增，P0）

盯盘人收盘后的固定动作只有三步。今日页在收盘时段（15:00 后）出现「盘后三件事」清单卡片，做完自动打勾：

1. **填价**：批量填价界面一次填完全部持仓（未填价醒目标注，支持"沿用上次价格"一键带出）
2. **看账**：当日总盈亏一眼可见（口径见下）
3. **复盘**：进入当日复盘表单（自动带出交易与计划对照）

**当日总盈亏口径（现金中性，不依赖现金账户即可计算）：**

> 当日总盈亏 = （今日收盘市值 + 当日卖出净得）−（昨日收盘市值 + 当日买入总花）
> 恒等分解 = 当日已实现盈亏 + 当日持仓的浮动变化

- 昨日收盘市值 = 昨日填价 × 昨日持仓数量（price_entries 已存逐日历史，数量由流水推导）
- 今日未填价的标的沿用最近一次填价估算，界面标注"约"；全部填完后精确到分
- 该指标进入今日页头条，替换目前"已实现 / 浮动"分列易误读的展示
- §5.12 资金流水上线后，切换为等价的权益口径：今日权益 − 昨日权益 − 当日净入金（权益 = 市值 + 现金）

### 5.12 入金出金与真实收益率（v0.3 从功能池提前，P1）

绝对盈亏 ≠ 能力，有本金才有收益率：

- 资金流水：入金 / 出金 / 分红（date, type, amount, note），期初本金一笔录入
- 现金余额自动记账：入金出金、买卖收付（含费）、分红都进现金账
- 权益 = 持仓市值 + 现金余额；净值 = 权益 ÷ 累计净入金；真实收益率 = 净值 − 1
- daily_snapshots 表的 principal / cash 字段已预留，落库即可画净值曲线与最大回撤
- 标的分红默认同时记一条 DIVIDEND 资金流水（可关），不影响持仓成本

## 6. 数据模型草案

| 表 | 关键字段 | 说明 |
|---|---|---|
| instruments 证券 | code, name, market(SH/SZ/BJ/HK/US/OTHER), type(STOCK/ETF/OTHER), is_favorite | 使用中自动积累的标的库 |
| trades 交易流水 | instrument_id, trade_at, side(BUY/SELL), price, quantity, fee, reason, emotion, images, tag_ids | 一切统计的唯一源头 |
| daily_reviews 复盘 | date(唯一), market_note, did_right, did_wrong, plan, mood(1-5), checklist, images | 一天一条 |
| price_entries 价格 | instrument_id, date, price | 手动填的价格，用于浮盈与市值 |
| daily_snapshots 快照 | date, principal, market_value, realized_pnl_cum | 每日复盘保存时自动生成，净值曲线数据源 |
| tags 标签 | name, type(STRATEGY/SECTOR/EMOTION), color | 策略 / 板块 / 情绪 |
| settings 设置 | key, value | 期初本金、佣金/印花税费率、提醒时间等 |
| cash_flows 资金流水 | date, type(DEPOSIT/WITHDRAW/DIVIDEND), amount, note | 入金/出金/分红，真实收益率数据源（§5.12，v0.3 新增） |

**已实现盈亏算法（移动加权平均，手续费计入成本）：**

- 买入：`新成本 = (原数量×原成本 + 买入数量×价格 + 手续费) / (原数量 + 买入数量)`
- 卖出：`已实现盈亏 += 数量 × (卖出价 − 持仓成本) − 手续费`，数量减少、成本不变
- 做空 / 保证金（期货期权）：v1 不支持（若市场范围含期货则为 P2）

## 7. 页面结构（信息架构）

底部 5 个 Tab：**今日 · 交易 · 持仓 · 复盘 · 统计**（设置入口在"今日"页右上角）。

```
┌─ 今日 ──────────────────┐   ┌─ 复盘（日历）───────────┐
│ 8月28日 周五        [⚙]  │   │ ←  2026年8月  →         │
│ 今日盈亏   +1,234.56     │   │ 一  二  三  四  五  六 日 │
│ 持仓市值   88,500        │   │  3   4   5   6   7  8  9│
│ 浮动盈亏   +5.6%         │   │ ●绿 ●红 ○空 ●绿 休  …  │
│ ── 今日交易 ──────────   │   │ ● = 已复盘（绿盈/红亏）  │
│ 买入 贵州茅台 100@1680   │   │ ○ = 漏复盘              │
│ ── 待办 ─────────────   │   └─────────────────────────┘
│ ⚠ 今天还没复盘 → 去填写   │
│              [＋ 记一笔]  │
└─────────────────────────┘
```

页面清单：今日仪表盘 / 记一笔（表单）/ 交易流水 / 持仓列表 / 已了结详情 / 复盘日历 / 复盘编辑 / 统计报表 / 设置。今日页头条为当日总盈亏，收盘后出现"盘后三件事"清单卡片（填价 / 看账 / 复盘，见 §5.11）。

## 10. 非功能需求

- **离线**：100% 功能离线可用（v1 除图片外无网络需求）
- **性能**：启动 < 2s；万条交易流水滚动流畅（分页 + 索引）
- **操作时长（v0.3 新增，"好用"的可度量定义）**：常用标的记一笔 ≤ 15s；盘后填完全部持仓价 ≤ 30s；写完一篇日复盘 ≤ 2min
- **可恢复性（v0.3 新增）**：任何误操作不丢数据——删除可撤销（回收站）、库可回滚（自动每日备份 + .pre-restore）
- **隐私**：数据不经允许不出设备；无第三方 SDK
- **精度**：金额 2 位小数；数量支持 3 位小数（碎股 / 场内基金）
- **设备**：华为 Mate X7（折叠屏，HarmonyOS NEXT）与 Mate 80（直板机）为主要目标设备；所有页面自 M1 起采用响应式布局（折叠态窄屏单栏，展开态宽屏双栏 / 大画布），折叠屏专项优化在 M3
- **语言**：中文界面；深浅色跟随系统
